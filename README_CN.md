# 自动关闭外部 RDP 标签页

[English](README.md)

通过 Electerm 的 RDP 书签启动 Windows 远程桌面客户端（`mstsc.exe`）后，插件会自动关闭对应的 Electerm 标签页。你可以在远程桌面窗口中登录并继续工作。如果客户端启动失败，标签页会保留，方便重试。

## 安装

请使用支持客户端插件资源和导入后自动运行的 Electerm Windows 桌面版。在 **设置 → 插件 → 导入** 中输入 `electerm/electerm-widget-native-rdp-no-tab`，也可以选择 **导入文件夹**，从本地克隆的仓库安装。

## 使用

在 RDP 书签中启用本地 RDP 客户端，然后打开书签。插件会在导入后立即运行，之后每次打开 Electerm 时也会自动运行。你可以在插件设置中关闭 **随 Electerm 启动**，也可以在 **运行中的实例** 中切换自动运行。点击 **停止** 可在当前会话中停用插件。

插件只处理成功启动外部客户端的 RDP 标签页。内置 RDP 会话和其他类型的标签页照常使用。
